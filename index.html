How an episode is made

My pipeline

A 9–10 minute documentary goes from primary-source research to delivered video through six stages. Each stage is backed by a tool I built so the next episode starts faster than the last.

  1. Research → scriptPrimary sources only; disagreements between accounts are stated, never smoothed over.
  2. Shot & visual planEvery shot mapped: which set, which people, which pose, which camera move.
  3. Sets in Blender (bpy)Procedural set builders turn a floor plan and archive photos into a lit, dressed 3D set.
  4. Posing in pose-threeMy browser posing studio: pose characters inside the real set through the shot camera, IK grips onto props, save with one keystroke.
  5. Render on the farmJob server drives the custom render engine on the GPU; supersampled stills and 2.39:1 frames with automated audits.
  6. Assembly & mixResolve edit, film grade, scored soundtrack ducked under narration, mixed to broadcast loudness.

Built, not bought

Tools I wrote for my own studio

I kept hitting walls in off-the-shelf tools, so I wrote my own. Each one runs in daily production.

01

Real-time render engine + farm

A custom-built real-time engine with a hand-built post chain — N8AO contact shadows, thin-lens depth of field, mip bloom, AgX tonemapping, SMAA, halation, film LUT — rendered supersampled and downsampled with Lanczos. A job server queues shots across the GPU and encodes with hardware H.264.

Custom engine · Node job server · GPU scheduling · 0.05 s/frame at 2× supersample
02

pose-three — character posing studio

A browser tool for posing characters inside the real set, through the real shot camera: IK with finger presets, drag-to-place with ground marks, in-set props with true grips, and a safe-save UX designed so no pose is ever lost by accident.

TypeScript · Vite · IK solvers · UX for daily artist use
03

Automated quality audits

Every still and camera move passes automated checks: hands-reach-target (reach-miss), no limb or prop penetrates geometry (ghost audit), camera rotation and zoom speeds stay inside comfort limits, and light intensities are budgeted in physical candela.

Computer-graphics QA · camera governors · lighting budgets
04

Procedural set builders

Headless Blender scripts that turn floor plans and archive photographs into dressed sets — cabin, motel, newsroom, mailbox — with procedural materials, decals and weathering, exported straight into the engine.

Blender bpy · procedural materials · asset pipeline
