3D artist portfolio: models, environments, sets and textures — and the documentary films they become.

**Live site:** https://amitkmarreji.github.io/Model-evidence/
**Channel:** https://www.youtube.com/@ModelEvidence

![EP04 mailbox set — modelled and dressed in Blender](assets/img/mailbox-hero.jpg)

## What this is

I make true-crime and history documentaries solo — every episode is rebuilt in 3D from primary sources, then lit, staged, rendered, scored and delivered end-to-end. This repository is the portfolio site for that work.

Three episodes shipped on YouTube (Alcatraz escape · the Mona Lisa heist · the $500M art heist). Episode IV is in production — all frames in the gallery are from its current build.

## Skills

Blender (model generation, environments, sets, texturing) · Unreal Engine · Unity · three.js (at times) · DaVinci Resolve · motion graphics · AI-assisted production under manual art direction.

I also build small internal tools that keep posing, rendering and quality checks fast — happy to walk through them in conversation.

## Site

Static single-page site — `index.html` + `assets/img/`. No build step. Served by GitHub Pages.
